# Testzweig: nur der Therapiepfad

Dieser Zweig enthaelt ausschliesslich die Anwendung aus dem Ordner `therapie/`
und die Schriftdatei, die sie braucht. Er dient dazu, die App ueber GitHub
Pages unter einer gesicherten Adresse auszuprobieren, bevor sie auf den
Webspace der Praxis kommt.

Die Praxis-Website liegt bewusst **nicht** in diesem Zweig: Sonst stuende sie
ein zweites Mal im Netz und koennte der echten Adresse bei Google schaden.

Der Zweig kann jederzeit geloescht werden. Gepflegt wird die Anwendung im
Zweig `claude/therapy-app-auto-update-c2tpkf` bzw. spaeter im Hauptzweig.
